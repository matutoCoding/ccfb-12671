# 粉末喷涂仿真系统

面向粉末喷涂代工车间的浏览器端仿真工具:TypeScript + WebGL2,**零后端、零运行时依赖**,打开即用。

## 快速开始

```bash
npm install      # 仅安装 typescript(开发依赖)
npm run build    # 编译 src/*.ts → dist/
npm start        # 启动静态服务器 http://localhost:8080
```

## 五个页面

| 页面 | 功能 |
|---|---|
| 工件库 | 客户加工明细表 CSV 导入(拖拽/选择文件),按行拆分工件,同图号自动合并数量,材质/期望膜厚从备注列解析,识别失败的行挂起等人工修改,结果存 IndexedDB |
| 喷房配置 | 前处理 7 槽工艺卡(浓度/浸泡时长/温度/单耗/换槽周期),按当天排产量自动算槽液补充量和换槽日期,超期槽标黄;喷房参数、粉末库存;往复机/固定枪两种喷枪建模,参数存为枪预设 |
| 喷涂仿真 | 选工件+枪预设,WebGL2 离屏计算静电场+粉粒运动,出膜厚热力图;死角标红、反电离橘皮区标品红;往复机运动干涉检查逐行程段算最小间距并给出改枪位/收摆幅建议 |
| 结果分析 | 每个工件每次仿真自动生成追溯档案(枪预设、槽液批次、膜厚结论、判定),按图号/工单号检索;不合格工件自动汇总返工清单并注明原因,可导 CSV |
| 产能核算 | 整班订单按颜色+材质分批合并,粉桶库存不足的批次标红提醒领料;每批拆粉末/槽液药剂/固化能耗/返工损耗四块成本,导出 CSV;方案导出/导入 JSON 打包发车间 |

## 仿真物理模型(2D 水平剖视)

- **距离场**:跳泛洪算法(JFA)在 GPU 上求欧氏距离变换,供法线/曲率/射线行进使用
- **边角积粉**:表面外凸处电场汇聚(法线散度>0),沉积通量乘场增强因子 → 边角膜厚偏高
- **法拉第笼**:沿法线半球 8 条射线球体追踪求"开阔度",深槽内壁开阔度低 → 上粉薄
- **反电离/橘皮**:局部场强 E = 电压/枪距 × 场增强,超过 ~8kV/cm 标记风险
- **沉积通量** ∝ 出粉量 × 电压 × 喷雾锥角 × cos入射角 × 距离衰减 × 开阔度 × 场增强
- 往复频率/链速折算停留时间;薄壁按最小特征尺寸(4px)等效建模避免离散伪影
- 512×512 网格,单次仿真约 0.3s(要求 <10s)

## 测试

```bash
node test/smoke.mjs   # 纯逻辑: CSV导入/几何/前处理/干涉/成本 (31 项)
node test/e2e.mjs     # 无头 Chrome 真实 WebGL2: 物理趋势/页面渲染 (19 项)
```

e2e 需要本机安装 Chrome(脚本内路径写死,可按需修改)。

## 鲁棒性

- 空 CSV、二进制垃圾、缺列、无数据行 → 报错提示或行挂起,不崩页面
- WebGL2/浮点扩展不可用 → 顶栏明确提示,其它功能正常
- IndexedDB 不可用(隐私模式)→ 降级为内存数据,页面仍可用
- 内置 10 个示例工件 + 默认喷房 + 7 槽 + 3 套枪预设,首次打开即可跑仿真
